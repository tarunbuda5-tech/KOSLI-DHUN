# KOSLI DHUN 🎵

Sambalpuri Music Streaming App

## About

KOSLI DHUN is a Sambalpuri music streaming application made to bring Sambalpuri songs together in one place.

## Features

- 🎵 Sambalpuri Songs
- 🔎 Search Songs
- ❤️ Favourite Songs
- 📚 Music Library
- ▶️ Music Player
- 🌙 Dark Theme
